# Beyond Steinhart-Hart: A Self-Calibrating Thermal Framework

## Overview

This repository contains research on a self-calibrating thermal framework using dynamic polynomial extrapolation for precise battery cell monitoring. The work presents an advancement over the traditional Steinhart-Hart equation for temperature measurement in battery management systems.

## Key Features

- **Self-Calibrating**: Automatically adjusts calibration parameters without manual intervention
- **Dynamic Polynomial Extrapolation**: Uses adaptive polynomial models for improved accuracy
- **Precise Battery Cell Monitoring**: Enhanced temperature measurement for battery management applications
- **Improved Accuracy**: Overcomes limitations of the classical Steinhart-Hart approach

- Battery Management Systems (BMS)
- Electric Vehicles (EV)
- Energy Storage Systems
- Thermal monitoring and control
- Precision temperature sensing

## Background

The Steinhart-Hart equation is a widely used model for converting thermistor resistance to temperature. This research introduces a novel framework that improves upon this classic approach by incorporating:

1. Dynamic polynomial extrapolation techniques
2. Self-calibration capabilities
3. Enhanced precision for battery cell monitoring scenarios
